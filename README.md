# Saúde360

Projeto de dashboard para acompanhamento de informações da saúde pública, com foco em Unidades Básicas de Saúde (UBS) e Unidades de Pronto Atendimento (UPA).

## Escopo planejado

- Visão Geral: painel de informações e indicadores.
- UBS: acompanhamento das unidades básicas de saúde.
- UPA: acompanhamento das unidades de pronto atendimento.
- Pacientes: área dedicada às informações de pacientes.

O projeto está em desenvolvimento. O escopo acima descreve as áreas planejadas, sem indicar que todas já estejam implementadas.

## Tecnologias

- Vue 3 e TypeScript
- Vite
- PrimeVue e Tailwind CSS
- Pinia e Vue Router
- Axios

## Executar localmente

```bash
npm install
npm run dev
```

## Verificações e build

```bash
npm run type-check
npm run lint:ci
npm run build
```
